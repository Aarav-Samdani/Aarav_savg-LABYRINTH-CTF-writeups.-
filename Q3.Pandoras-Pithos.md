\# Pandora's Pithos



The challenge provides an image called `pandora\_box.jpeg`. The flag is hidden inside it.



\## Finding the hidden file



A JPEG can have other files appended to it. To check, upload the image to CyberChef, an online tool, and use the `Extract Files` operation. This finds a `.zip` archive inside the image, saved as `extracted\_at\_0x4bca0.zip`. Extracting it shows one file, `scroll.txt`, but the archive is password protected.



\## Cracking the password



John the Ripper can crack zip passwords. After downloading it, open the `run` folder inside the John the Ripper files and open Command Prompt there.



First, convert the zip's password into a hash John can read:



```text

zip2john.exe "C:\\Users\\XYZ\\Desktop\\extracted\_at\_0x4bca0.zip"

```



This prints the hash to the screen. Save it to a file instead by redirecting the output:



```text

zip2john.exe "C:\\Users\\XYZ\\Desktop\\extracted\_at\_0x4bca0.zip" > "C:\\Users\\XYZ\\Desktop\\hash"

```



Then run John on the saved hash file:



```text

john "C:\\Users\\XYZ\\Desktop\\hash"

```



John finds the password. If it's already cracked from a previous run, it can be shown again with:



```text

john --show "C:\\Users\\XYZ\\Desktop\\hash"

```



Either way, the password is:



```text

andreina

```



\## Reading the scroll



Extract `extracted\_at\_0x4bca0.zip` using the password `andreina`. This gives `scroll.txt`, which contains the flag.



\## Flag



```text

labyrinth{p4nd0r4s\_s3cr3t\_unl34sh3d}

```
