# XORinth

The challenge provides us with a Python script called `chall.py`, and its output called `out.txt`.

```python
import os

FLAG = "labyrinth{fake_flag}"
KEY = os.urandom(2)
inner_flag = FLAG.split('labyrinth{')[1][:-1]
ct = [ord(char) ^ KEY[i % 2] for i, char in enumerate(inner_flag)]

print("ct =", ct)
```

```text
ct = [167, 108, 254, 3, 255, 108, 167, 50, 253, 3, 171, 111, 150, 54, 188, 105, 254, 3, 171, 104, 252, 109, 170, 3, 187, 108, 254, 3, 254, 52, 248, 105, 150, 107, 248, 49, 250]
```

The key observation is that `KEY` is only 2 random bytes, reused across the whole message cyclically (`KEY[i % 2]`). So there's only 256 × 256 = 65,536 possible keys, which is brute forcable.

For every possible key, decrypt the ct and keep the output where every character is either a lowercase letter, digit, or underscore:

```python
ct = [167, 108, 254, 3, 255, 108, 167, 50, 253, 3, 171, 111, 150, 54, 188, 105, 254, 3, 171, 104, 252, 109, 170, 3, 187, 108, 254, 3, 254, 52, 248, 105, 150, 107, 248, 49, 250]

allowed = "abcdefghijklmnopqrstuvwxyz0123456789_"

for key1 in range(256):
    for key2 in range(256):
        key = (key1, key2)

        flag = ""
        for i in range(len(ct)):
            if i % 2 == 0:
                byte = ct[i] ^ key1
            else:
                byte = ct[i] ^ key2
            flag = flag + chr(byte)

        correct = True
        for c in flag:
            if c not in allowed:
                correct = False

        if correct == True:
            print("key =", key1, key2)
            print("flag =", flag)
```

This gives us:

```text
flag text = n07_60nn4_b3_ju57_b451c_r07_7h15_71m3
```
