\# Q.1- Eisodos

Locate the welcome flag hidden within the labyrinth ctf 2026 discord server



\## Solution

1. \*\*Join the server\*\* First, join the official Labyrinth CTF 2026 Discord server.
2. \*\*Find first half\*\* Navigate to the `#rules` channel. Inspect the channel description (topic) at the top of the screen to find the first half of the flag: labyrinth{w3lc0m3\_t0`
3. \*\*Find second half\*\*Next, navigate to the `#ai-rules` channel. Inspect this channel's description in the same way to find the second half:`\_th3\_labyrinth}`


\## Flag

combining both parts reveals the final flag: 

`labyrinth{w3lc0m3\_t0\_th3\_labyrinth}`
