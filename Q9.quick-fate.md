# Quick Fate

We are given a small game. If you survive long enough, a victory screen prints the flag.

Playing it is the obvious but the wrong path. The flag can be decoded using a key from the code of the game. The game only runs that code when you win, but the code can be forced by us as well.

## Overview

This is the whole chain we end up following:

```text
1. FUN_00401dc0   end screen: param_2 == 0 is defeat, otherwise victory
2. FUN_004011b0   copies the text into the output buffer, replacing ' ' with '_'
3. FUN_00401130   XOR-decodes 24 bytes with key 0x5a
4. DAT_00416210   the 24 encoded bytes
```

## Ghidra

Ghidra is a free reverse-engineering tool which makes it so we can read what the program does without having its source.

Ghidra names function addresses in the format of `FUN_<address>` and data in the format of `DAT_<address>`

## Finding the flag function

Go to Search and in that select For Strings and click Search to search for every string in the file. Here try typing messages you could get on winning including 'win', 'victory. The string preferred while this solve was 'Flag' considering the victory screen would have 'Flag' along with it. By doing this, we find: 

```text
"VICTORY! YOUR FLAG IS %s"
```

The `%s` is a format specifier, to interpret the string input, which is the Flag.

Double-click the entry to jump to it. We find a `XREF` label next to the string, showing where in the code the string is used. Double-click this to jump to the instruction that pushes the string's address inside the function that draws the end screen, `FUN_00401dc0`using the code `PUSH s_VICTORY!_YOUR_FLAG_IS_%s_0041e040`

## Following the function chain

```c
void __cdecl FUN_004011b0(int param_1,uint param_2)
{
  undefined1 uVar1;
  undefined *puVar2;
  int local_8;

  puVar2 = FUN_00401130();
  for (local_8 = 0; (local_8 + 1U < param_2 && (puVar2[local_8] != '\0')); local_8 = local_8 + 1) {
    if (puVar2[local_8] == ' ') {
      uVar1 = 0x5f;
    }
    else {
      uVar1 = puVar2[local_8];
    }
    *(undefined1 *)(param_1 + local_8) = uVar1;
  }
  *(undefined1 *)(param_1 + local_8) = 0;
  return;
}
```

 The function:

1. Gets the text of the flag from `FUN_00401130()`.
2. Goes through the text one character at a time, stopping either when the text has ended, or when the 25 character limit has been completed. (24 technically, as one is reserved for the final 0, or the end marker.)
3. Copies each character into the  buffer, but it replaces the space with `0x5f`, which is the ascii code for (`'_'`).
4. Writes an end marker after the final character

Double-click `FUN_00401130` to go into it, as, we saw that that's where the text is taken from.

```c
undefined * FUN_00401130(void)
{
  int local_8;

  if (DAT_0041eab4 == 0) {
    for (local_8 = 0; local_8 < 0x18; local_8 = local_8 + 1) {
      (&DAT_0041ea98)[local_8] = (&DAT_00416210)[local_8] ^ 0x5a;
    }
    DAT_0041eab0 = 0;
    DAT_0041eab4 = 1;
  }
  return &DAT_0041ea98;
}
```

Reading this:

- `DAT_0041eab4` is an "already decoded" marker . First it is 0, to run the decoder, after which it turns 1 to directly get the result.
- `local_8` is the loop counter. It runs from 0 to 0x18, to ensure maximum 24 bytes are processed.
- `(&DAT_00416210)[local_8]` is the encoded byte being procesed.
- `^ 0x5a` is the main encoder its an XOR, xor-ing with `0x5a`
- The result goes into `DAT_0041ea98`, the decoded text buffer.
- `DAT_0041eab0` runs after 24 decoded bytes, hence acts as the end marker.

Two details matter here. The key is a constant, and the encoded bytes sit in the data of the game. Because the bytes and key are fixed, we can decode them ourselves without winning.

## Getting the encoded bytes

Double-click `DAT_00416210` in the decompiler to jump to it. We get 24 bytes which are:

```text
6a 12 7a 03 6a 0f 7a 1b 16 17 6a 09 0e 7a 1e 6b 69 1e 7a 0e 12 69 08 69
```

## Decoding

To decode this, we dont need to write any python scripts. Since it is a simple xor encode with a fixed key, we can open CyberChef and input the 24 bytes. Then we perform 2 operations, first we add **From Hex** with the delimiter as Space, and then **XOR** with key as 5a(hex). Doing this we get: 

```text
0H Y0U ALM0ST D13D TH3R3
```

Swapping the spaces for underscores, the same way the game does, and adding the `LABYRINTH{}` wrapper gives the flag.

## Flag

```text
LABYRINTH{0H_Y0U_ALM0ST_D13D_TH3R3}
```
